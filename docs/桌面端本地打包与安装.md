# 桌面端本地打包与安装

统一入口为仓库根目录的 `scripts/build-app.sh`。默认只构建，不安装、不启动；macOS 生成的 `.app` 可直接运行，`.dmg` 用于分发。

```bash
# 生成默认平台安装包
./scripts/build-app.sh

# macOS：只构建 .app，并安装或更新 /Applications 中的应用
./scripts/build-app.sh --install

# macOS：构建、安装并启动
./scripts/build-app.sh --open

# 同时保留 DMG 分发产物并安装
./scripts/build-app.sh --install --bundles dmg,app

# Linux：只构建 Debian 包或 AppImage
./scripts/build-app.sh --bundles deb
./scripts/build-app.sh --bundles appimage
```

Linux 在交互终端中未指定 `--bundles` 时会询问要生成的格式；非交互环境默认构建 `deb,appimage`。可用 `--bundles deb` 或 `--bundles appimage` 跳过未选格式，减少打包耗时；也可传 `--bundles all` 构建全部受支持格式。`--debug` 可以与上述参数组合；用于快速验证，不推荐分发。`--help` 显示完整用法。安装选项仅支持 macOS，应用名称和标识从 Tauri 配置读取。

Linux `.deb` 中的主程序和 sidecar 安装在 `/opt/ButvanAgent/`，`/usr/bin/` 保留指向 `/opt` 文件的符号链接供桌面入口与 sidecar 调用。打包脚本会按后端 JAR、JDK 版本和目标架构缓存最小 JRE；这些输入未变化时复用运行时，避免重复执行 `jlink`。首次构建或输入变化时仍会生成运行时。

macOS 按本机构建架构生成应用与 sidecar。Intel Mac 使用 `x86_64-apple-darwin`，Apple Silicon 使用 `aarch64-apple-darwin`；需在对应架构设备上使用匹配架构的 Rust 工具链和 JDK 构建。当前流程不生成 Universal Binary，也不支持跨架构 sidecar/JRE 构建。

更新前请从应用菜单栏选择“退出（停止所有任务）”；仅关闭窗口可能仍会后台运行。脚本遇到运行中的同名进程会停止安装，构建产物仍保留。安装需要 `/Applications` 写入权限，脚本不会自动使用 sudo。

建议始终用 `--install` / `--open` 原地替换，不要先删除 `/Applications` 里的应用再安装。删除应用本身不会清数据，但第三方卸载/清理工具会连带删除 `~/Library/Application Support/com.butvan.agent`、`~/Library/WebKit/com.butvan.agent` 等按应用身份派生的目录；桌面端长期偏好与后端业务数据已统一放在 `~/.butvan-agent/`（`desktop/` 为偏好，`data/`、`config.json` 为业务数据），不受应用删除影响，备份时保留该目录即可。

安装通过暂存完整新版后替换旧版完成；替换失败时恢复旧版。目标是符号链接或不同 bundle ID 的应用时拒绝覆盖。安装不会修改用户配置、数据库或通知授权记录。若系统已经拒绝通知权限，重新安装并不保证再次出现授权弹窗。

macOS 默认由 Tauri 对完整应用执行 ad-hoc 签名（`bundle.macOS.signingIdentity: "-"`），确保签名标识与 `CFBundleIdentifier` 一致。仅保留链接器生成的可执行文件签名时，标识可能是 `RecordAgent-…`，系统通知服务会拒绝 `com.butvan.agent` 的授权请求，导致没有弹窗、通知列表也无此应用。正式分发可以通过 `APPLE_SIGNING_IDENTITY` 指定 Developer ID 证书，公证仍按发布流程配置；本地 ad-hoc 签名不等于 Apple 公证。

排查通知权限时，检查 `codesign -dv --verbose=2 /Applications/ButvanAgent.app` 的 `Identifier` 是否为 `com.butvan.agent`，并运行 `codesign --verify --deep --strict /Applications/ButvanAgent.app`。系统请求错误应显示为授权失败，不得直接解释为用户拒绝，也不应添加 Apple 私有通知 entitlement 来规避身份校验。

成功后终端分别显示构建产物位置和安装路径；仅构建时明确提示未更新已安装应用。当前产物路径沿用项目默认的 `agent-frontend/src-tauri/target/{release,debug}/bundle`，自定义 Cargo 输出目录或交叉编译配置需要另行适配。
