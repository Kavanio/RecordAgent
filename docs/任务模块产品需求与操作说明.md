# 任务模块产品需求与操作说明

## 创建和管理

任务包括自定义提醒、日报、周报、月报和久坐提醒。可选桌面通知与发送邮件；周期报告不调用 AI，支出、待办、学习分别从对应领域读取。数据读取失败与没有记录分别展示。

## 本机与远程后端

桌面设置中的“后端连接”允许保存远程 API 地址。选择远程地址后，重启 App 才切换；远程模式不会启动本机 sidecar，任务配置、报告生成、邮件队列和业务数据由服务器持续处理。本机仍负责系统通知、提醒窗口、休息遮罩与久坐使用状态采样；电脑关机或 App 完全退出时，这些本机能力暂停，服务器不会伪造本机活动数据。

远程连接通过服务器 `BUTVAN_API_TOKEN` 校验 Bearer Token；桌面端将 Token 存入操作系统钥匙串。远程服务器必须设置 `BUTVAN_API_REQUIRE_TOKEN=true`，并将 Token 放入权限受限的服务环境配置；可使用 `openssl rand -hex 32` 生成 Token，禁止提交到仓库或写入普通日志。健康检查 `/api/health` 也验证 Token。浏览器原生 SSE 与头像/附件 GET 使用受限的查询令牌入口，部署必须使用 HTTPS 或可信 VPN，并限制服务器防火墙可访问设备，只将实际桌面运行来源加入 `BUTVAN_CORS_ALLOWED_ORIGINS`。Spring Boot TLS 可通过 `BUTVAN_SERVER_SSL_ENABLED=true`、`BUTVAN_SERVER_SSL_KEY_STORE`、`BUTVAN_SERVER_SSL_KEY_STORE_TYPE` 和 `BUTVAN_SERVER_SSL_KEY_STORE_PASSWORD` 配置；证书及密码须由权限受限的服务文件提供。当前业务仍是单用户数据库，不得作为多用户服务或暴露到公网。普通桌面通知离线超过 15 分钟会标记为跳过，避免重连后集中弹出旧通知；人工待确认提醒仍会保留。

列表按全部、已开启、已暂停、已结束筛选；已删除任务只保留历史。编辑器切换任务、新建、复制或关闭时，如有未保存内容，会先询问是否放弃。保存期间不允许切换编辑对象。复制任务默认暂停，并保留其邮件模板。

任务页顶部展示后台运行、系统通知与邮件可用性，进入任务设置可以调整。浏览器模式只有应用内提醒，不采集电脑使用状态。彻底退出桌面应用后，调度和邮件发送均停止；希望关闭窗口后继续运行，需开启后台运行，通过菜单栏图标管理或退出。

## 周期报告与邮件模板

日报统计任务时区内计划执行日当天截至生成时的数据并对比前一天；周报统计上一个周一至周日并对比上上周；月报统计上一个自然月并对比上上月。周报可选每周一个发送星期，月报固定每月 1 日发送。支出按币种分别显示本期、上期、差额及变化百分比；上期为零时仅显示差额，不计算百分比。日报启用“支出”栏目时，同时列出报告生成时的各资产账户余额、该日每个账户的收入和支出合计及逐笔收支（时间、分类、备注、金额）；自动收益按收入展示，划账和余额校准单列为其他资产变动，不计入收支。旧日历支出因未绑定资产账户，会单独列为未关联账户的账单。待办展示应办、完成、完成率及最多 8 条未完成事项；学习展示时长与记录数。任一周期没有待办时完成率标为不适用。每个来源的本期与上期分别降级，无法比较时明确标注；日报资产与账户流水读取失败时独立标注，不影响其他栏目。

报告邮件当前固定使用“蓝调摘要”，任务编辑器展示当前模板说明；点击“预览（不发送）”检查实际 HTML。预览不写执行记录、不发送邮件。

| 样式 | 表现 |
| --- | --- |
| 蓝调摘要 | 参考私人日报纸张排版，留白分节、轻量绿红数据强调；账户和账单按内容对齐，避免重复分割线 |
模板配置随任务保存，复制报告任务可复用。旧任务保存的样式标识（包括旧自定义模板）在读取和预览时统一转换为蓝调摘要；旧主题色、标题、正文和页脚不再参与渲染，下次保存任务时归一化持久化。已生成的历史邮件仍保留原 HTML 快照，重发继续使用该快照。邮件主题使用任务标题。金额显示币种和两位小数，生成时间显示到分钟并标明任务时区；报告统计已结束的完整自然周期。

每次执行冻结正文与 HTML。修改任务后，重发历史邮件仍使用原正文、原样式；升级前没有 HTML 快照的历史记录沿用兼容排版。

## macOS 原生提醒与确认

无需确认的任务在安装版通过 macOS `UNUserNotificationCenter` 提交原生通知，展示任务标题和正文摘要；前台也请求横幅与默认声音，提交接口等待系统接纳后才返回。是否展示横幅、保留提醒及声音仍受“系统设置 → 通知 → 本应用”和专注模式控制。开发可执行文件没有稳定的应用包身份，因此开发模式的普通提醒使用应用内消息和提示音。需确认的任务在安装版和开发模式均使用固定尺寸的全局提醒窗口，窗口到点播放提示音，确认后立即停止。

开启“需要手动确认”的任务会弹出独立窗口，任务页不重复展示黄色提醒卡片。窗口无内容滚动条，一次展示一条提醒；多条待确认提醒依次呈现，过长正文会截断。久坐任务点击“确认并开始休息”后按配置的休息分钟数倒计时，期间窗口不可关闭；倒计时结束后自动调用后端确认，成功时按任务声音设置播放一次结束提示音、关闭窗口，并从零重新计时。倒计时状态在客户端保存，窗口重载后可恢复；待确认期间不会重复生成提醒。普通提醒点击确认后立即关闭，不改变原计划。久坐检测当前仅支持 macOS，读取空闲与锁屏状态，不读取屏幕或键盘内容；达到配置的空闲阈值、锁屏、超出任务生效时段或采样中断时暂停累计并保留已保存进度，重新活动后继续计时。采样缺失期间的时长不会推算补入；客户端离线或后端重启时，本机采样暂停，后端保留已持久化的累计进度，重连后继续。

## 提醒窗口偏好

设置页面统一保留上下滚动能力但不显示滚动条，任务设置由外层页面统一滚动；开发模式提醒复用统一 LeverSwitch，以禁用态显示当前启用状态。

在“任务设置 → 提醒窗口”中配置，修改自动保存在当前电脑，下一次提醒读取；开关与音色切换立即保存，播放间隔输入完成后失焦或回车保存，失败会回退并提示。任务自身的“声音”开关仍决定是否发声；无需确认的系统通知横幅沿用操作系统通知设置。

- **休息时锁定桌面**：默认关闭。开启后，只有点击“确认并开始休息”并进入倒计时才显示多屏遮罩；等待确认和普通提醒不锁定。设置页的锁屏效果预览使用独立租约，不会被提醒窗口的空闲释放命令关闭。倒计时期间持续同步显示器布局，接入、拔除或重新排列显示器时更新遮罩覆盖范围，并适配 macOS 各显示器不同的缩放比例。倒计时结束即恢复操作，即使后端确认失败也不继续遮挡。短暂连接中断时停止心跳续约但保留已显示遮罩，避免 SSE 瞬时断连导致遮罩闪烁；恢复连接后在原生租约到期前继续续约，持续断连时由 6–15 秒原生租约自动释放。提醒窗口退出或倒计时结束立即释放。布局同步遇到暂时错误时保留现有遮罩并重试；首次创建失败会清理半成品。遮罩阻止普通鼠标点击，保留系统快捷键，不锁定系统账户，不拦截系统安全界面。
- **提示音**：提供清亮铃声、柔和风铃、双音提醒、上升音阶、轻柔单音五种内置音色；macOS 枚举 `/System/Library/Sounds`，Windows 枚举系统 Media 目录，通过统一下拉选择器选择。未发现系统音色时仍可使用内置和上传音频。
- **上传音频**：支持当前系统可解码的 WAV、MP3、M4A、OGG，文件不超过 10 MB。导入时检查扩展名、文件头与可播放性；不支持的编码会提示改用 WAV 或 MP3。上传成功即选用该音频，再次上传替换上一文件。音频只复制到本机，不发送至服务器。试听只播放一次，可停止，离开设置页会停止，且不影响正式提醒。
- **重复播放间隔**：1–3600 整数秒，默认 4 秒；每段音频完整播放结束后才开始等待，不重叠播放。点击确认立即中断声音和等待；久坐休息完成且后端确认成功时，播放一次所选结束音。

桌面偏好及上传音频由 Tauri 应用配置目录的 `task-reminder/` 管理：`settings.json` 保存音色 ID、重复间隔和锁定开关，上传音频使用应用生成的文件名。配置损坏时记录日志并回退至不锁定桌面的默认值。原生命令只允许固定系统音频目录和应用管理的音频文件，不接收任意文件路径；休息遮罩命令仅允许提醒窗口调用，上传和保存仅允许主窗口调用。

### 桌面 IPC 契约

| 命令 | 输入与结果 |
| --- | --- |
| `task_reminder_configuration` | 无输入，返回 `preferences`（`restLock`、`soundId`、`repeatSeconds`）和 `sounds`（`id`、`name`、`source`） |
| `save_task_reminder_preferences` | 主窗口提交完整 `preferences`；音色必须存在，间隔为 1–3600 秒，失败返回中文错误 |
| `import_task_reminder_audio` | 主窗口提交 `name` 和 `bytes`；完成校验和本机保存后返回最新配置 |
| `read_task_reminder_audio` | 提交枚举的系统音色 ID 或 `custom`，返回音频字节，不接受路径 |
| `task_reminder_audio` | `action` 为 supported/play/status/stop，`channel` 为 preview/reminder；分别仅供主窗口/提醒窗口使用，内置音色播放可传 WAV `bytes`，返回支持或正在播放状态 |
| `sync_task_rest_lock` | 提醒窗口提交 `remainingSeconds`，0 释放，正数续约 6–15 秒；已有遮罩遇到暂时同步错误时保留并返回错误，首次创建失败清理半成品 |
| `preview_task_rest_lock` | 主窗口提交 `remainingSeconds`，0 只释放设置页预览租约，正数启动限时预览；不会释放正式休息租约 |

## 调度和投递

- 普通定时提醒迟到超过一分钟会记录为跳过，不连续补发离线历史。
- 报告仅补计划发送当天最近一次，且仍须处于生效时段；间隔任务重启后重新起算。
- 一次性任务结束后需编辑未来时间才能重新启用。预览无未来时间时明确显示没有可执行时间。
- 手动“立即执行”会真实通知或发邮件，操作前有确认，不改变下次计划时间。
- 邮件只能发往当前已验证、允许通知的绑定邮箱，发送前再次检查授权。
- 邮件内容生成、桌面提交、邮件提交、人工确认分别展示；“已提交”不等于用户已读。
- 发送结果未知时禁止自动重发。用户检查收件箱并确认重复风险后，可以重发原邮件。
- 排队超过 24 小时自动跳过；手动重试从新入队时刻重新计时，原执行时间不变。
- 执行历史在右侧抽屉中展示任务概况、生成内容与各通知渠道结果；采用极简文字列表和留白分组，不使用时间线或卡片边框。桌面、邮件、确认状态以图标表示，成功高亮，悬浮和辅助技术可读取具体状态；未启用且该次跳过的渠道不展示，保留曾实际投递的历史渠道。抽屉随 SSE 状态变更重新读取，失败时可手动重试，不使用定时轮询。
- 任务搜索位于列表工具栏右侧，以轻量背景呈现；已删除列表提供逐项恢复和清空入口。恢复后的任务保持暂停，需用户手动启用；清空二次确认后永久删除当前用户全部已删除任务及其执行历史，搜索筛选不限制清空范围。

## 接口契约

所有接口位于 `/agent/automations`，以服务端当前用户为权限边界，不接受客户端 ownerId。响应沿用 `Result<T>`；非法配置、版本冲突、不可重试状态返回项目统一业务错误。

| 方法与路径 | 输入 | 响应与作用 |
| --- | --- | --- |
| GET `/` / GET `/stream` | 无 | 任务和待确认记录快照；SSE 建连与重连先发送 snapshot |
| POST `/` / PUT `/{id}` | `{ spec, enabled, version }` | 保存任务；更新需匹配版本 |
| POST `/{id}/state` | `{ enabled, version }` | 暂停或恢复 |
| DELETE `/{id}?version=...` | 当前版本 | 软删除并撤回未开始通知 |
| POST `/{id}/restore?version=...` | 已删除任务当前版本 | 恢复为暂停；版本冲突、任务不存在或已达 200 个活动任务时拒绝 |
| DELETE `/deleted/purge` | 无 | 永久清空当前用户全部已删除任务及历史，返回清空任务数；前端先二次确认 |
| POST `/preview` | Spec | `{ title, content, nextAt, html }`，只读预览 |
| POST `/{id}/run` | 无 | 手动执行的 RunView |
| GET `/{id}/runs` | 无 | 最近 50 条执行记录 |
| POST `/runs/{id}/retry-email` | `{ allowUnknown }` | 显式重发原内容，刷新入队时间 |
| POST `/runs/{id}/claim`、`/receipt`、`/confirm` | 无 / `{ status }` / 无 | 原子领取、提交回执、人工确认 |
| POST `/activity` | `{ idleSeconds, locked, supported }` | 原生使用状态采样 |
| GET / PUT `/mail/settings` | 无 / SMTP 配置 | 查询脱敏配置或保存；不发送 |
| POST `/mail/test` | 无 | 用户主动发送不含业务数据的测试邮件 |

`spec.mailTemplate.style` 当前只支持 `DIGEST`。为兼容既有客户端和数据库记录，传输对象仍接受 `{ style, accent, heading, introduction, footer, body }` 旧字段，但已知旧样式标识（`CARDS`、`MINIMAL`、`LETTER`、`EDITORIAL`、`LEDGER`、`RECEIPT`、`CUSTOM`）会统一映射为 `DIGEST`，其余旧字段被忽略并在下一次保存时归一化。未知样式拒绝保存。

Flyway V19 增加任务模板配置、执行 HTML 快照和本次邮件入队时间。数据库仍由后端唯一写入，真实邮箱与凭据不进入前端任务响应。

## 验证

后端使用临时 SQLite 和模拟邮件服务验证调度、确认、预览、模板保存、安全转义与跨日重试。前端使用内存 DOM 验证状态筛选、编辑切换、草稿保护与历史同步；测试不访问用户后端。自动化测试覆盖播放结束后的重复时序、取消播放、确认前不锁定、确认后倒计时锁定、短暂断连保留遮罩、重连续约和倒计时结束释放；原生层验证默认偏好和上传校验。多显示器遮罩的窗口层级、系统声音实际输出、原生通知展示与各邮件客户端最终排版需在安装包和真实系统中验收。

任务列表采用最大 920px 居中版心，搜索靠列表工具栏右侧，不展示顶部运行条件白框；相关配置通过顶栏任务设置入口管理。任务同步未就绪持续超过 1.5 秒时通过全局 Message 提示一次，恢复后提示同步成功，不在页面内显示黄色横幅。

创建/编辑任务时，点击“预览（不发送）”后打开独立预览弹窗，显示生成进度、失败重试及邮件排版或提醒正文；关闭后保留草稿，再次打开使用最新草稿。预览与保存共用必填、通知渠道、生效星期和报告栏目校验。关闭桌面通知会同时关闭声音和手动确认；久坐提醒固定开启桌面通知与手动确认。
