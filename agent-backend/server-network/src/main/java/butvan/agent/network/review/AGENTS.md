# 长期复盘模块契约

本目录遵守根目录与 server-network 的 AGENTS.md。修改授权、事实或目标时先阅读根目录 `docs/自动长期记忆复盘教练实施方案.md`，以实际阶段记录区分已实现与规划。

## 当前阶段

- 已提供配置、独立授权、事实摘要、用户目标、建议与反馈、有界模型生成和邮件两段式冻结。默认关闭；未显式授权时不得调用模型，公开响应保持 `generationAvailable=false` 直到具备执行能力。
- 生成只在独立 `review-worker` 线程执行，事实采集与模型调用都在事务外；原任务调度线程只做短事务入队，不等待模型。
- 默认关闭；配置保存不是授予权限。授权必须显式确认 policyVersion、绑定固定 Provider ID、模型、协议、地址指纹、数据域、周期和最长窗口；扩大范围或改变接收方后必须重新授权，撤销立即使本地摘要写入权限失效。
- 聊天与 Slash Command 不得复用本模块的授权；每次生成前重新校验授权 revision、连接身份与每日额度，模型固定为授权时选择的连接。
- 模型草案必须经 `ReviewDraftValidator` 校验：证据／目标／方法／行动 ID 白名单、长度与数量上限、无依据数字、心理诊断与投资承诺一律拒绝或丢弃；校验通过不宣称推理正确。
- 邮件等待副本在 AI 成功或到期后一次性冻结；晚到结果不补发、不改写。撤销授权与清除数据必须禁用未冻结副本，已发送邮件无法撤回。
- 建议的采纳与结果只由用户反馈驱动，未反馈保持未知；被纠正或否定的观察不再作为召回证据。
- 个人目标与召回候选由 `ReviewMemoryReader` 的业务 Adapter 权威读取；当前仅开放后台复盘用途，聊天和飞书接入须增加独立用途权限，并通过既有上下文预算 seam，不复用报告授权。
- 预览只保存结果和依据，不创建长期行动或观察；生成结果提交事务中再次核对授权、配置版本与期限，失效结果不得发布。

## 目录与数据职责

- `controller/` 仅做协议适配，当前用户由 CurrentUserProvider 提供，所有方法标注 ApiLog。DTO 正文不得在日志中展开。
- `dto/` 只保存独立请求／响应契约；`model/` 为内部领域记录；`repository/` 仅访问 review 领域表；`service/` 封装校验、事务与跨领域只读组合。
- 新表使用追加式 Flyway 迁移，业务路径仍为 `~/.butvan-agent/data/butvan.db`；测试只使用临时数据库。
- 模型身份只读检查用户现有 config.json，不自动初始化／改写文件，不测试模型连接，不保存 Key，也不接受客户端提交可信的地址指纹。
- 金额为最小单位整数，分币种；时长为秒；计数为整数。缺失来源独立标为 UNAVAILABLE，不当作零。失败不保存原始异常或用户备注。
- 本目录原统计摘要只处理已结束自然日，最多回看 180 天、单次最多 7 日；不收集当天未闭合窗口，不从邮件文本反向解析，不读取聊天／资料正文。
- 出厂重置使用独立 `ReviewResetParticipant`，事务内关闭个人化配置、撤销授权、禁用未冻结 AI 副本，清除事实快照、生成结果、建议、观察与反馈；人工目标及已冻结的报告／邮件副本保留，后者不作为记忆召回源。原 `erase` 接口的“同时删除目标”语义保持独立。
- 显式清除必须在同一事务中关闭配置、撤销授权、删除当前用户的快照／目标；采集落盘前重新检查配置与授权版本，防止清除后数据复活。过期快照当前在查询时不可见、下一次采集时清理，完整后台保留期清理仍须在模型自动执行上线前补齐。
- 原始账本补录后重新采集产生新指纹，但已冻结的旧摘要不改写；摘要用于历史证据，不宣称是不可变历史账本。
- 用户目标只由用户显式创建、修改和归档；不能把模型观察写成用户目标或画像。所有写入使用 revision／事务，所有查询检查 owner，列表有数量上限。

## 生活复盘扩展

- `life/AGENTS.md` 为生活复盘、版本、主动时机及跨渠道投递的子级契约；修改这些能力前必须读取。
- `life-v1` 授权独立于本模块原统计授权。原 Fact 和闭合自然日规则保持不变，文字材料和当天草稿由 life 模型承载；模型输入的 narratives 只由该授权入口提供。
- 统计与生活模型调用按用户共享执行名额；生活复盘重置参与方独立清理派生材料与作息候选，已外发或结果未知副本保留为不参与召回的只读存档。
