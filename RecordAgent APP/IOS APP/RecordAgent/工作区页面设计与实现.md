# iOS 四个工作区：设计与实现

2026-09-30。以桌面客户端的业务结构为参考，为触屏重新组织内容。四个入口从固定按日预览升级为独立工作区；返回工作台后保留月份、搜索、筛选和专注状态。

视觉统一采用系统背景、原生导航、大标题、充分留白、平面列表和细分隔线。财务用橙红表达支出、青绿表达收入，分类采用稳定的低饱和配色；图表共享页面纯净背景与完整内容宽度，页面不以多层统计卡片组成。搜索使用轻量底线，筛选使用文字与短下划线，新增位于顶部；编辑、保存中和错误反馈共用同一组件。适配中英文、深浅色、动态字号与安全区。

| 页面 | 首屏结构 | 详情与操作 |
| --- | --- | --- |
| 财务 | 月份切换、彩色资产与收支摘要、账户、收支趋势/账户收支/支出排行、搜索和真实流水 | 按账户查看流水、交易明细、建立账户、记收入/支出；金额使用整数分，提交重试保持幂等键 |
| 资料 | 分类文字导航、搜索、收藏/回收站筛选、标题和短摘要 | 按需读取完整正文、独立写作、版本化保存、收藏、移入回收站及恢复；手记仍与日历共用同一条记录 |
| 记录 | 当前专注、月份切换、轻量月统计、搜索和时段列表 | 开始/结束专注、补录、时段详情与删除；服务端保存活跃时段，重启后恢复真实开始时间，跨日沿用同一学习事实 |
| 任务 | 真实配置列表、搜索/启停筛选、通知权限和本机注册状态 | 创建/编辑/暂停/启用/删除；支持一次性、每日、每周、每月本地提醒，详情查看实际设备观察到的通知历史 |

财务统计和记录统计读取完整聚合，分页列表不会冒充统计总量；资料正文在打开条目时加载。所有页面通过独立服务协议请求真实 API，不注入演示数据。加载、无内容、失败、重试和版本冲突在所属内容附近表达，保存失败保留草稿。

用户已确认任务首期采用 iPhone 本地通知。配置保存到服务端，当前手机通过系统通知中心注册提醒，退出应用后已注册的提醒仍由系统执行。权限拒绝、配置已保存和通知注册成功分开展示；登录及返回前台时按服务端配置对账，退出/鉴权失效时移除本机提醒。月提醒限定 1–28 日，每账户最多 32 个未来启用提醒。配置在别处变化后，此手机下次前台对账才生效。

通知历史仅记录手机系统实际返回的送达观察，不把注册成功记成已送达，也不宣称完整投递审计。本期任务侧重手机自动提醒；日报邮件、服务器推送、桌面任务迁移和多设备只提醒一次仍需后续方案。资料附件、富文本和自定义分类 Tab 沿用现有数据模型后续扩展，本次提供纯文本写作与固定业务类型筛选。

已在 `AppEnvironment` 装配服务，并由 `MainTabView` 持有四个页面的状态对象；原 `WorkspacePreviewView` 已移除。工作区写入后刷新共享首页，日历在进入时重读数据。后端新增接口详见 [工作区接口契约](../backend/工作区接口契约.md)，手机任务表通过追加 V6 迁移建立。

按用户要求，本次省去最终编译、完整测试及本机 Docker 验证，仅进行格式/语法静态检查、接口字段和代码复核。新后端接口与 V6 需要在实际运行环境更新后使用；真机权限、通知投递和完整联调尚未验收。

## 财务图表与工作区面板更新（2026-09-30）

三个图表对齐桌面业务能力：趋势显示分类堆叠支出柱、橙红支出实线和青绿收入虚线，可触摸/拖动查看日期、收支及分类金额；账户横向柱图切换收入/支出，金额按钮可展开两个方向的明细；支出排行切换分类/单笔，显示金额与占本期支出比例，默认前五名并支持展开全部。无真实记录时展示空态，不填充示例。

周/月/年均以工作区选中日期为锚点，周从周一开始；周/月按日，年按月汇总。分析通过现有服务读取完整账户分页和覆盖月份的全部流水页，不受流水搜索、类型和账户筛选影响。只在完整读取成功后发布聚合，切换周期隔离旧结果，取消传播，金额整数分聚合检测溢出。当前接口不提供分析专用聚合或分页快照，年视图的请求数随流水规模增长，并发写入时跨页读取不承诺事务快照；超过 10,000 个账户或 100,000 条流水/游标安全边界明确失败，不展示部分统计。大规模数据后续应改为服务端完整聚合接口。

账户选择使用图标卡片、余额和选中圈，默认半屏，可拉至全屏，底部固定新建入口。账户创建、收支创建、资料、记录、任务的共享编辑器改为分组背景、大标题与关闭入口、单层圆角输入区域、底部固定保存；保存失败保留草稿，处理中禁用退出。财务、资料、记录与任务详情沿用同一分组面板；日历专属纸张便签仍按自身契约实现。

本次验证使用 Xcode 模拟器构建及财务分析、财务/资料领域和国际化单元测试；未进行截图或手动界面检查，真机外观及大字号体验需要设备验收。

## 手机图表适配复核（2026-09-30）

移除分析区域的灰色底色与内外两层卡片缩进，三个模块直接使用页面画布。周/月/年与账户、排行模式共用等宽 44 点分段按钮；周期本地化改为显式静态键，避免显示 `finance.range.*`。趋势采用自然日/月整数位置与明确首尾刻度，两端各留半格、金额刻度保留顶部余量；无金额的方向隐藏曲线，不把单笔月末支出伪造为连续活跃数据。支出/收入摘要提供线型图例、金额和结余，触摸明细保留分类。

账户图改为名称与金额在上、横向条形柱在下的手机排版，省去拥挤的纵轴账户名和重复列表，点击可展开两个方向金额；默认前五个账户并可展开全部。分类/单笔排行保留金额与占比；名称和金额无法同行时自动上下排列，辅助字号直接纵排。视觉验收使用测试宿主中的 SwiftUI 与 Swift Charts 实际渲染，包含 320 点单笔月末记录、390 点多笔收支及英文辅助字号；夹具只用于临时验收，不进入真实业务页面或服务。
