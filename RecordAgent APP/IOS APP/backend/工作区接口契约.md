# 原生工作区 API 契约

2026-09-30。所有接口位于 `/api/v1`，除已公开认证入口外均从认证会话取得用户 ID。不存在和越权读取返回 404，期望版本不匹配返回 409；分页 `{items,nextOffset,hasMore}`，页大小遵守 `ReadBounds`，关键词最多 200 字符。列表、正文和完整聚合各有独立读取边界。

| 方法与路径 | 输入及响应 | 业务约束 |
| --- | --- | --- |
| GET `/finance/overview` | `month=YYYY-MM` → `totalAssetsInCents,expenseInCents,incomeInCents,transactionCount` | 当前总资产与指定月完整收支；不由一页流水求和 |
| GET `/finance/transactions/page` | `month,type?,accountId?,query?,offset?,limit?` → Transaction 分页 | 类型仅 `expense/income/空`；日期、时间、ID 降序；账户与关键词在数据库筛选 |
| GET `/finance/accounts/page` | `offset,limit` → Account 分页 | 复用已有账户接口 |
| POST `/finance/accounts`、`/finance/transactions` | 沿用既有 DTO | 收支提交复用 UUID 幂等键、余额与流水同事务；本次不改变划账规则 |
| GET `/library` | `type?,favorite?,trash?,query?,offset?,limit?` → Item 分页 | 列表只含标题、180 字符摘要、字数、收藏/回收状态与版本；不随列表下发整篇正文 |
| GET `/library/{id}` | → Document | 本人的完整纯文本正文和版本 |
| POST `/library` | Save → Document | Save 为 `id,date,type,title,body,timeZone,version`；客户端 UUID 使相同未确认草稿幂等重试 |
| PUT `/library/{id}` | Save → Document | 日期、类型、标题、正文在同一版本化更新；不编辑回收站内容 |
| PATCH `/library/{id}/flags` | `version,favorite,trashed` → Document | 收藏、软删除和恢复；手记与日历仍为同一 ID/事实 |
| GET `/study` | `month,timeZone,query?,offset?,limit?` → Entry 分页 | 已结束时段与目标月重叠；返回完整开始/结束时间；跨日投影沿用既有日历服务 |
| GET `/study/overview` | `month,timeZone` → `minutes,sessionCount,activeDays` | 全量聚合，排除未结束时段 |
| GET `/study/active` | → Entry 或空响应 | 同一账户最多一个活跃时段；应用重启恢复服务端开始时间 |
| POST `/study` | `id,title,startedAt,endedAt?,timeZone` → Entry | 无 endedAt 为开始专注，有 endedAt 为补录；同 UUID 同内容重试不重复创建 |
| PATCH `/study/{id}/finish` | `version,endedAt` → Entry | 完成前校验所有权和版本；同结束时间重试幂等；已完成区间 1 分钟至 7 天，结束不晚于当前允许时钟偏差 |
| DELETE `/study/{id}` | `version` | 放弃活跃计时或删除完成记录；共享日历/个人统计相应改变 |
| GET `/tasks` | `query?,enabled?,offset?,limit?` → Task 分页 | enabled 为空读全部；筛选在分页前执行 |
| GET `/tasks/{id}` | → Task | 编辑冲突时可重新读取权威配置 |
| GET `/tasks/enabled` | → Task 数组 | 最多 32 个未来启用配置，供手机对账；已过期一次性配置不再注册 |
| POST `/tasks`、PUT `/tasks/{id}` | Save → Task | 创建用客户端 UUID；修改用版本；配置字段见下文 |
| DELETE `/tasks/{id}` | `version` | 软删除、停用，保留已观察历史；手机对账移除通知 |
| POST `/tasks/{id}/deliveries` | `eventId,deliveredAt` | 设备只在系统确实返回送达通知后上传；事件 ID 幂等，未来时间拒绝；仅为设备观察事实 |
| GET `/tasks/{id}/deliveries` | `offset?,limit?` → `id,deliveredAt` 分页 | 观察历史；不宣称完整投递审计或报告执行历史 |

资料类型保持 `quick/learning/weekly_review/reading/journal`；周复盘的 ISO 周年/周数由日期推导。正文最多 100,000 字符，标题最多 240 字符。本次写作使用纯文本，附件、富文本、标签和自定义资料 Tab 后续沿用既有资产/资料模型扩展。

手机 Task/Save 字段为 `id,title,body,recurrence,hour,minute,weekday?,dayOfMonth?,onceDate?,timeZone,enabled,version`。`recurrence` 为 once/daily/weekly/monthly；一次性必须有 onceDate；每周使用 ISO 星期 1–7；每月只允许 1–28，保证每个月有该日期；其他不适用字段必须为空。启用一次性任务必须晚于当前时间。通过用户行锁限制同一账户最多 32 个未来启用提醒。

追加 `V6__mobile_tasks.sql` 建立 `mobile_task` 和 `mobile_task_delivery`，不改写已应用迁移。任务配置是服务端事实，当前设备使用 UNCalendarNotificationTrigger 执行本地通知；权限拒绝或注册失败不能伪造生效状态。手机下次登录/回到前台时同步配置变化，退出账户清除其通知。日报邮件、服务器推送、桌面任务迁移及多设备只投递一次均不在本期实现。

本次按用户要求省略最终编译、完整测试及本机 Docker；真实数据库迁移、通知权限和真机投递尚待运行环境验收。
