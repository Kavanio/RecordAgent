## 在同一局域网联调

1. 先确认 `.env` 指向**专用开发数据库**。应用启动会执行 Flyway 迁移，不要用生产或其他任务正在使用的数据库做接口写入测试。配置数据库与 SMTP；SMTP 未配置时健康接口可用，但验证码返回 503。
2. 在本机 `.env` 设置 `RECORDAGENT_SERVER_ADDRESS=0.0.0.0`，然后重启后端。只在可信局域网内临时使用 HTTP；正式部署使用 HTTPS。
3. 在 Mac 查询当前局域网 IP：`ipconfig getifaddr en0`。启动后用 `curl http://<电脑IP>:9090/actuator/health` 确认返回 `{"status":"UP"}`，并检查系统防火墙允许 Java 接收入站连接。
4. 手机接入相同局域网，在 Debug 版 App 的“我的 → 设置 → 测试服务器”输入 `http://<电脑IP>:9090`，点击“检测连接”。地址会随网络变化，切换网络后重新填写。

安全默认值是 `127.0.0.1`，不会对局域网开放；本机被忽略的 `.env` 可覆盖此值。数据库端口仍只应对本机或受控网络开放。Debug 测试页只保存不含凭据的地址，访问令牌不得放入该设置。

## 已知待补

- 生产 HTTPS、正式邮件投递与文件存储部署策略尚未配置；没有 SMTP 就无法从客户端注册真实账户。
- 密码登录、验证码发送需要进一步做跨实例限流和审计；当前验证码已有 60 秒同邮箱限频、10 分钟过期、5 次尝试和一次性消费。
- 日历完整编辑删除和工作台完整业务仍待实现。iOS 的任务入口明确未开放。
- 现阶段尚未完成独立 PostgreSQL 集成测试或真机点击验证；不要将主机侧 `curl` 等同于手机侧验收。
