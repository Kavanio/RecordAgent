待办创建的 `date` 是生效起点；`recurrenceWeekday` 仅用于 `weekly`，采用 ISO 星期（1=周一，7=周日），省略时兼容旧客户端为周日。非每周携带星期、星期超出 1–7 或非法周期返回 400；周/月待办不保存具体时间，每月固定自然月末。周便签按整周实际发生日读取，完成记录仍按周一/月初归一化；周期读取日期/时区非法返回 400，未认证返回 401，数据库不可用返回 503。

认证、待办、日程、手记、收支、当日投影、个人统计与资料图片已接入真实 API。工作台当前只提供按日只读投影，完整资料管理、学习写入、日历编辑删除、任务以及附件绑定仍按 [iOS页面与接口清单.md](iOS页面与接口清单.md) 开发。Debug 地址可在登录页或设置页填写，Release 需要配置 HTTPS 地址。

## 在同一局域网联调

1. 先确认 `.env` 指向**专用开发数据库**。应用启动会执行 Flyway 迁移，不要用生产或其他任务正在使用的数据库做接口写入测试。配置数据库与 SMTP；SMTP 未配置时健康接口可用，但验证码返回 503。
2. 在本机 `.env` 设置 `RECORDAGENT_SERVER_ADDRESS=0.0.0.0`，然后重启后端。只在可信局域网内临时使用 HTTP；正式部署使用 HTTPS。
3. 在 Mac 查询当前局域网 IP：`ipconfig getifaddr en0`。启动后用 `curl http://<电脑IP>:9090/actuator/health` 确认返回 `{"status":"UP"}`，并检查系统防火墙允许 Java 接收入站连接。
4. 手机接入相同局域网，在 Debug 版 App 的“我的 → 设置 → 测试服务器”输入 `http://<电脑IP>:9090`，点击“检测连接”。地址会随网络变化，切换网络后重新填写。

安全默认值是 `127.0.0.1`，不会对局域网开放；本机被忽略的 `.env` 可覆盖此值。数据库端口仍只应对本机或受控网络开放。Debug 测试页只保存不含凭据的地址，访问令牌不得放入该设置。

## 明细与统计读取契约

旧日详情、流水和账户列表保持原有成功 DTO；超过配置上限返回 HTTP 422、`RESULT_LIMIT_EXCEEDED`，不返回截断结果。月摘要及趋势统计覆盖全部记录，月摘要不加载正文，最多返回每月 31 个日期摘要。

- `GET /api/v1/calendar/days/{date}/pages/{kind}?timeZone=Asia/Shanghai&offset=0&limit=100`：需认证；`kind` 为 `todo/schedule/journal/finance/study`，`items` 使用对应日详情领域 DTO。
- `GET /api/v1/finance/accounts/page?offset=0&limit=100`：需认证；`items` 使用账户 DTO。
- 返回 `{items,nextOffset,hasMore}`；无下一页时 `nextOffset=null`。`offset>=0`，`1<=limit<=recordagent.reading.day-limit`，非法参数返回 400。
- 稳定排序包含业务 ID。offset 分页期间有新增/删除时应从第一页刷新；当前 iOS 旧日列表尚未自动改用分页，超限会明确加载失败，后续客户端可接入上述分页入口。

## 收支幂等与认证策略

`POST /api/v1/finance/transactions` 可携带 UUID 格式的 `Idempotency-Key`，所有权仍由 Bearer 身份决定。同用户、同键、完全相同 DTO 返回首次成功响应（含当时余额）；换任意字段返回 409 `VERSION_CONFLICT`。事务失败不登记键，重试可继续；不同用户互不复用响应。无键保留旧客户端行为，不提供重复提交保护。

iOS 同草稿及当前进程内同内容的未确认提交复用键；成功后下一次提交使用新键，自动续期重试也保留键。进程重启后的未知提交没有自动恢复保证，不自动重发。

认证 POST 来源默认 60 次/60 秒，密码登录同邮箱默认 10 次/60 秒，均由 PostgreSQL 共享；验证码保留同邮箱同用途 60 秒冷却和 5 次校验限制。过期限流桶保留一天后清理。反向代理默认不读取不可信转发头，部署前需要配置可信来源，避免所有用户被按代理 IP 归为同一桶。BCrypt 密码限 72 UTF-8 字节，超限注册/重置返回 400，登录返回 401。

## 统一错误语义

| HTTP 状态 | code | 语义 |
| --- | --- | --- |
| 400 | INVALID_ARGUMENT | JSON、必填参数、字段、UUID、时区或分页参数无效 |
| 401 / 403 | UNAUTHENTICATED / FORBIDDEN | 会话无效 / 权限不足 |
| 404 | NOT_FOUND | 本人资源不存在，越权对象也按不存在处理 |
| 409 | VERSION_CONFLICT | 期望版本、唯一约束或幂等键内容冲突 |
| 405 / 415 / 406 | METHOD_NOT_ALLOWED / UNSUPPORTED_MEDIA_TYPE / NOT_ACCEPTABLE | 请求方法、Content-Type 或 Accept 不支持 |
| 422 | RESULT_LIMIT_EXCEEDED | 旧明细列表超限，改用分页 |
| 429 | RATE_LIMITED | 认证来源、密码登录或验证码额度不足 |
| 503 | SERVICE_UNAVAILABLE | 数据库连接、查询超时、邮件或存储暂不可用 |
| 500 | INTERNAL_ERROR | 未预期实现错误，包括 SQL 编写错误 |

错误体 `requestId` 与响应 `X-Request-Id` 一致；错误正文不包含用户输入、SQL、异常原文或凭据。财务和手记日期使用写入时选择的自然日，不按查询时区重新投影；学习使用绝对时间按请求时区裁剪，跨午夜和夏令时按真实日边界计算。
